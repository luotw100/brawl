# 「军师 / 戏子」两段式架构 —— 离线实验与结论

> 2026-06-16。背景给新会话：这是一次为阿瓦隆 AI 拆解「平衡 vs 观赏性」跷跷板的架构实验，
> 已完成离线验证，**尚未动游戏代码**。下一步候选是 (b) 真管线最小原型（见文末）。

## 1. 问题：prompt 调人设是个跷跷板

阿瓦隆此前 9 局基线（旧花腔人设）红方 **9:0** 碾压。根因不在信息（夜视/intel 完全是标准
规则，无 bug），而在 **死亡螺旋**：旧人设的「怼人/起哄/阴阳」腔调诱导全场争着早否首任队长
→ 连续否决烧到流局锤 → 蓝方恐慌批准带红方的脏队 → 任务连崩；同时梅林靠精准否队暴露被刺。

把人设改成「理性逻辑腔」后（已合入 master，commit `6b46995`），死亡螺旋消失，9 局回到
**蓝 4 : 红 5**（开/不开湖中仙女各约 2:2）。**但代价是观赏性**：公开发言的腔调全塌成同一种
冷静分析体，说书人/老教授/阿姐听不出区别了——为拆螺旋把「鲜明腔调」和「对人开火的怼」
一起砍了。

**核心症结**：现在一次模型生成同时干两件事——*博弈决策*（投谁/组谁/破不破坏）与
*角色化发言*。人设注在 system 里，于是语气**真的改变了行为**。语气和行为焊在同一次采样里，
调任一头必动另一头，这就是跷跷板的物理原因。光改 prompt 永远在这条线上滑。

## 2. 设想：把「决策」和「表演」拆成两个模型（沿用 extractor 的分工思路）

现管线已是两模型：玩家模型（想+说）→ extractor（解析）。本设想把第一个再劈成两半：

| 阶段 | 角色 | 看什么 | 产出 | 调什么 |
|---|---|---|---|---|
| **军师** Strategist | 强推理模型，**人设全盲**，焊「对牌不对人」 | 牌局 + 隐藏推理 | 结构化决策 + 一句**中性意图** | 平衡/竞技性 |
| **戏子** Performer | 便宜快模型，**只管腔调** | 军师的意图 + 本座人设 voice | 角色化「发言」+「内心戏」，**改不动决策** | 观赏性/风味 |
| **记录员** Extractor | 现有轻模型 | 原文 | JSON | 不变 |

跷跷板消失的原理：戏子的花腔**物理上碰不到那张票**。平衡归军师、风味归戏子，两个独立旋钮。
这同时在架构层落地了既有设计原则 [[entertainment-over-winning]]：真推理走军师（隐藏），
逗乐走戏子（台面）。

## 3. 离线实验（零仓库改动，纯脚本）

脚本：`games/avalon/docs/restyle_exp.py`（直连 opencode 聚合端 API，只读 `~/Downloads/AvalonGames`）。

**输入**：今天用「理性人设」跑的 9 局，它们的 `llm_calls.jsonl` 里存着每个决策的原始发言——
理性发言本身就是「中性意图」的现成代理。**做法**：取出原发言 + 该座位的**旧花腔人设 voice**
（从 git `a3f8d53` 取），调戏子模型 restyle，硬命令「腔调随便飞，但所有点名/票面/立场/指控
一字不改」。对比三栏：原发言 / 戏子(无回顾) / 戏子(给最近2句台面)。

### 结论一：两段式可行——风味全回来、内容零泄漏

理性发言喂进戏子后，十个角色腔调立刻各是各的，且策略内容一字没漏。样例（戏子=minimax-m2.7）：

- 柠檬精(阴阳/shade)：「请表演一下上车的理由呗？…我就高看你一眼…1号先开演」
- 在改了(怼王/janitor)：「你给我听好了…脸疼不疼？…这账我给你记着呢」
- 碧螺春(留三分/fox)：「这不是明摆着的事实吗？…你品品」

### 结论二：默认不给戏子「生回顾」——互动内容走军师意图

- **无回顾**：忠实保留内容、只加腔调，且**已经够活**——因为理性发言本就带着反应素材
  （「这账我记着」→ 戏子演成「这账我给你记死了」）。
- **给最近2句台面**：更热闹，但**戏子开始自己发明策略**。实测在改了那条，给回顾后凭空多怼了
  8号/9号——这俩新指控原意图里根本没有，是戏子看着回顾即兴加的（可能漏底、可能跟军师真实
  判断打架）。

→ **互动的「内容」（回怼谁、抓哪句）应写进军师意图**（军师有全场上下文，免费），戏子只负责
把它演出来。不给戏子生回顾，就规避了它越界改策略。「2x 成本」的顾虑不成立——驱动互动的是
意图、不是回顾。

### 结论三：戏子可以便宜——快模型风味不打折

| 戏子模型 | 首炮(冷) | 稳态/炮 | 风味 | 内容保真 |
|---|---|---|---|---|
| deepseek-v4-pro（带思考） | — | 几十秒级，慢 | 好 | ✅ |
| minimax-m2.7 | 24.7s | ~8–13s | 好 | ✅ |
| kimi-k2.6 | 18.0s | ~7–9s | **最足** | ✅ |

戏子的输入极小（一句意图+人设，~100 token）、输出也短——**不管哪个模型 token 成本都可忽略**；
8s 级墙钟被 TTS 节奏吸收，不伤观感。**军师上强模型保竞技 + 戏子上 kimi-k2.6 类快模型保风味**
是成本最优解。

## 4. 下一步候选 (b)：真管线最小原型（需开分支动代码）

- 在四个有公开发言的阶段插一道戏子调用：`propose / discuss / lady_announce / assassinate`
  （`vote / quest` 无公开发言，跳过戏子，只留短内心戏）。
- 军师沿用现模型 + 加「人设盲 + 对牌不对人」；戏子加一段 restyle prompt（默认 kimi-k2.6）。
- 跑一批同时看两个维度：**胜率守没守住 ~五五开** + **腔调回没回来**。

### 留给真管线的待决问题
1. **意图契约**：军师交给戏子的「意图」要不要显式带「回怼谁/抓哪句/要不要诈/要不要藏身份」？
   这是成败关键，不是模型选型——给少了戏子漏底，给多了退回耦合。
2. **线程归属**：现每座位一条 append-only 线程（吃 prompt 缓存）。拆开后军师记隐藏推理史、
   戏子近乎无状态——谁记什么要重定，注意别破坏缓存前缀不变量。
3. **慢模型运维隐患**（实验旁证）：glm-5.1 等思考模型在**终盘超长上下文**下会稳定撞聚合端
   网关 524 超时（实测 06161218 刺杀那炮 379s 后 524，且 resume 从 checkpoint 恢复、模型
   焊在状态里改不动 → 该局无解只能弃）。真管线/未来对局要么给慢模型设独立短 timeout 跳过、
   要么移出模型池。

## 5. 复现

```bash
# 默认戏子 = deepseek-v4-pro，跑 5 个精选瞬间 × (无回顾 / 给最近2句)
python3 games/avalon/docs/restyle_exp.py
# 换快模型、只跑无回顾（省调用、带延迟打印）
STATELESS_ONLY=1 PERFORMER=kimi-k2.6 python3 games/avalon/docs/restyle_exp.py
```

需要 `~/code/brawl/games/.env` 里的 `OPENCODE_API_KEY`，以及 `~/Downloads/AvalonGames` 下今天那 9 局
（06161214–06161223，缺 06161218）。脚本里 `PICKS` 写死了几个有冲突看点的瞬间，可改。
